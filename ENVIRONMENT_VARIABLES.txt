ACCOBIZ EXCEL CONVERSION UTILITY - ENVIRONMENT VARIABLES
=======================================================

-------------------------------------------------------
1. REDIS_URL            (REQUIRED on Vercel, optional elsewhere)
-------------------------------------------------------
  Purpose : Database for open conversions and saved Settings.
            Vercel runs the app as many short-lived instances, so a conversion
            must be stored in a shared database, not in memory.
  Value   : A Redis connection URL, e.g.
            rediss://default:xxxxxxxx@your-db.upstash.io:6379
  How to get it on Vercel:
            Project -> Storage -> Create Database -> Redis (Upstash, from the
            Marketplace) -> Connect to project. Vercel adds REDIS_URL (or KV_URL;
            both names are accepted) automatically. Redeploy afterwards.
  If not set: conversions are kept in memory and Settings in
            rules/accobiz/stock_settings.yaml - fine on your own PC or a single
            always-on server, but on Vercel you will get
            "Conversion session expired" errors and Settings cannot be saved.

-------------------------------------------------------
2. ANTHROPIC_API_KEY    (optional)
-------------------------------------------------------
  Purpose : Enables "Review with AI" for ledgers in "Everything else".
  Value   : Your Anthropic API key from https://console.anthropic.com
            (starts with  sk-ant-...)
  If not set: everything else works; the AI panel says "not set up".

-------------------------------------------------------
HOW TO SET THEM
-------------------------------------------------------
Vercel  : Project -> Settings -> Environment Variables (REDIS_URL is added for
          you when you connect the Redis database). Redeploy after changes.
Local PC: copy .env.example to .env and fill in the values, then restart
          start.bat. Never commit .env (it is in .gitignore).

-------------------------------------------------------
GOOD TO KNOW ON VERCEL
-------------------------------------------------------
  - Upload limit: Vercel accepts request bodies up to about 4.5 MB per upload.
    Normal ledger / stock exports are far smaller.
  - Conversions are kept in Redis for 4 hours after the last action, then expire.
  - Default Settings (rates, HSN list, unit) come from
    rules/accobiz/stock_settings.yaml; once someone saves Settings in the app,
    the saved copy in Redis is used instead.
  - AI review can take up to about a minute for large files; keep the function
    timeout (Project -> Settings -> Functions -> Max Duration) at 60s or more.
